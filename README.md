# Hi There 👋

I'm an **MLOps Engineer** and **Software Developer** specializing in high-throughput AI infrastructure, asynchronous system architecture, IaC, and applied machine learning. I focus on building scalable vector pipelines, optimizing cloud deployments, and orchestrating multi-agent LLM workflows.

### 🚀 What I Do (The Technical Stuff)
* **MLOps & AI Pipelines:** designing and scaling multi-model embedding pipelines in Python under high velocity data speeds. 
* **Cloud & Infrastructure:** Managing high-concurrency ingestion layers, asynchronous worker pools, and optimizing AWS infrastructure via CDK.
* **Local LLMs & Orchestration:** Heavy experimentation with local models via Ollama, Flash Attention, and KV caching. I build custom Model Context Protocol (MCP) servers and unattended Claude Code subagents for multi-disciplnary tasks.
* **Data Science & ML:** Pursuing an M.Sc. in Machine Learning & Data Science.
